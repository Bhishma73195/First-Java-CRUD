# FirstRestAPI

## 📌 Project Description
This project is a simple REST API developed using **Spring Boot** as part of **Task 2** for the Spring Framework course at **Vistula University**.

The application demonstrates the use of:
- REST controllers
- Layered architecture
- Spring Data JPA
- H2 in-memory database
- Swagger (OpenAPI)
- Exception handling

---

## 🧱 Project Structure

The project follows a layered architecture:

- **api** – handles HTTP requests and responses
- **service** – contains business logic
- **repository** – handles database operations
- **domain** – contains entity classes
- **support** – contains mappers and exception handling
- **shared** – common response objects

---

## 🛠 Technologies Used

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Springdoc OpenAPI (Swagger)
- Maven
